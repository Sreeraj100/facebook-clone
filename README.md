# Facebook Login Page Clone

## Overview
A static clone of the Facebook login page created using HTML and CSS. This project aims to replicate the visual design of the Facebook login interface.

## Features
- Styled login form with placeholders and buttons.
- Layout and design resembling the Facebook login page.

## Technologies Used
- **HTML5**: For the structure.
- **CSS3**: For styling.
